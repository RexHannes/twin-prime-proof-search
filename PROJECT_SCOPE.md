# Project scope — Twin Prime programme

This repository is the living research/formalization record for the fixed-shift / Ford–Maynard / Twin-Prime programme.

## Active-scope rule

The living status ledger, current frontier, dependency graph and analytic/source owner map must contain only Twin-Prime-programme objects.

A theorem, source pin, packet owner, compiler or conclusion belonging to a separate problem is not an admissible dependency merely because the two projects use related sieve or Type-II technology.

## Generic-lemma rule

A source-neutral finite/algebraic lemma may be reused if its statement is genuinely generic. Reuse does not transfer any problem-specific status, source realization, analytic estimate or conclusion.

## Separate-repository rule

Erdős Problem #287 is maintained in `RexHannes/erdos-287-proof-search` and is not part of the active theorem graph here.

Historical cross-project material remains recoverable from Git history for provenance, but it is noncontrolling and is not imported into the living Twin-Prime status/compiler graph.

## Public-status rule

The repository must continue to state

```text
TWIN_PRIME_CONJECTURE: OPEN
```

until the full global source package, required Ford–Maynard Type-II input and final implication are genuinely complete.
