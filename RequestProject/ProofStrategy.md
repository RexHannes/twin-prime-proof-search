# Proof Strategy for the Bounded Smooth Reciprocal Circuit Conjecture

## Conjecture (BSRCC)

For every smoothness bound *y* and entropy deficit δ > 0, there exists *C(y, δ)* such that if *Q* is a finite set of *y*-smooth composite integers with |*Q*| − *H*₂(*Q*) ≥ δ, then *Q* contains disjoint nonempty *A*, *B* ⊆ *Q* with *R*(*A*) = *R*(*B*) and |*A*| + |*B*| ≤ *C*(*y*, δ).

---

## 1. Three Proof Strategies

### 1.1 Strategy A: Graver / Primitive Integer-Kernel Route

#### Setup

After clearing denominators by *L* = lcm(*Q*), a reciprocal identity *R*(*A*) = *R*(*B*) becomes

∑_{a ∈ A} L/a = ∑_{b ∈ B} L/b.

Define weights *w_q* = *L*/*q*. The identity is a vector **z** ∈ {−1, 0, +1}^*Q* in ker(**w**ᵀ), where *z_q* = +1 if *q* ∈ *A*, *z_q* = −1 if *q* ∈ *B*, *z_q* = 0 otherwise. A *primitive* identity is one that cannot be conformally decomposed into two smaller kernel vectors with {−1, 0, +1} entries — equivalently, a Graver basis element restricted to {−1, 0, +1} coefficients.

#### The exact theorem this route would need

**Theorem A (Smooth Graver Support Bound).** Let *p*₁, …, *p_r* be distinct primes. For any finite set *Q* of {*p*₁, …, *p_r*}-smooth positive integers, every primitive {−1, 0, +1}-valued element of ker(**w**ᵀ) has support at most *f*(*r*), where *f* depends only on the number of primes *r* = π(*y*) and not on the magnitudes of the elements of *Q*.

#### Why it might be true

The weights *w_q* = *L*/*q* = ∏ *p_i*^{*M_i* − *v_{p_i}*(*q*)} where *M_i* = max_{*q*′∈*Q*} *v_{p_i}*(*q*′). These weights lie in the multiplicative monoid generated by *r* primes. The key algebraic constraint is:

The equation ∑_{j ∈ S⁺} *w_j* = ∑_{j ∈ S⁻} *w_j* with all *w_j* being products of *r* primes is an *r*-parameter Diophantine problem. Intuitively, with only *r* "degrees of freedom" (the prime exponents), one might expect that a primitive solution needs only *O*(*r*) terms to achieve cancellation.

**Heuristic analogy:** In finite abelian groups, the Davenport constant *D*(*G*) bounds the length of the longest zero-sum-free sequence, and for *G* = ℤ_{*n*₁} × ⋯ × ℤ_{*n_r*}, we have *D*(*G*) = 1 + ∑(*n_i* − 1). The Graver support bound for {−1, 0, +1} coefficients is an infinite-group analogue. While direct Davenport-constant results apply to finite groups, the structural similarity suggests bounded support.

**Partial evidence from the data:** For *r* = π(7) = 4 primes, the observed support bound is 7 ≈ 2*r* − 1. For *r* = π(13) = 6 primes, the observed bound is still 7, which does *not* fit *f*(*r*) = 2*r* − 1 but might indicate the bound grows slowly or is dominated by small-prime structure.

#### First nontrivial lemma to prove

**Lemma A1 (Two-prime Graver bound).** For *r* = 2 (primes {*p*, *q*}), every primitive {−1, 0, +1}-valued partition identity among {*p*, *q*}-smooth positive integers has support at most 4.

*Why this might be accessible:* For two primes, the exponent vectors lie in ℤ² and the weights *w* = *p*^*a* · *q*^*b* have a strong multiplicative structure. The key identity pattern is the "diamond":

1/(*p*^*a* · *q*^*b*) + 1/(*p*^*c* · *q*^*d*) = 1/(*p*^*e* · *q*^*f*) + 1/(*p*^*g* · *q*^*h*),

which after clearing denominators becomes an identity among four {*p*, *q*}-smooth numbers. A primitive such identity involves four terms (support 4) because with three terms and two primes, the identity *p*^*a* = *p*^*b* + *p*^*c* (with *b*, *c* < *a*) has limited solutions for a single prime, and mixing two primes gives the diamond pattern.

*Sketch of why support ≤ 4:* Consider a primitive identity ∑_{S⁺} *w_i* = ∑_{S⁻} *w_j*. Order terms by *p*-adic valuation. The element with smallest *v_p* on side S⁺ must be "matched" on side S⁻ (otherwise, dividing out *p* from all other terms would violate primitivity by creating a smaller identity). With two primes, one layer-peeling step for *p* and one for *q* should resolve the identity in at most 4 total terms.

**However:** This sketch has a gap — the layer peeling might need to iterate if elements at the extremal layer don't fully cancel. Proving Lemma A1 rigorously is the critical test of this approach.

#### Most likely obstruction

**Exponent growth.** For generic (non-smooth) integer programs, Graver basis elements can have support proportional to log(max entry). The standard Cook-Gerards-Schrijver-Tardos bound for a 1 × *n* matrix **w** gives Graver elements with entries bounded by the largest entry of **w** — but this bounds *entry size*, not *support*. For {−1, 0, +1} entries, the support bound comes from the maximum number of ±1's needed to cancel, which for a single-row matrix can be as large as *O*(log *w_max*).

For *y*-smooth weights, *w_max* = *L* can be exponentially large, so the generic bound gives support *O*(*N*), which is useless. The question is whether the multiplicative structure of the weights provides a better bound. **If the answer is no** — if there exist primitive {−1, 0, +1} identities among *y*-smooth numbers with support growing with the range of exponents — then this approach fundamentally fails.

**Specific potential counterexample to Theorem A:** Consider primes {2, 3} and the identity:

2^0 · 3^*n* + 2^*n* · 3^0 = f(n)

where *f*(*n*) is some sum of {2, 3}-smooth numbers. If the shortest expression of 3^*n* + 2^*n* as a sum of {2, 3}-smooth numbers (other than itself) requires many terms, this would give a primitive identity of growing support. We investigate this in Section 4.

### 1.2 Strategy B: *p*-adic Layer-Peeling Route

#### Setup

For each prime *p* ≤ *y*, define the *p*-layer of *q* ∈ *Q* as *v_p*(*q*). In a reciprocal identity *R*(*A*) = *R*(*B*), consider the *p*-adic valuation structure.

Write the identity as ∑_{*a* ∈ *A*} 1/*a* = ∑_{*b* ∈ *B*} 1/*b*. For each prime *p*, define the *p*-level sets:

*A_k* = {*a* ∈ *A* : *v_p*(*a*) = *k*}, *B_k* = {*b* ∈ *B* : *v_p*(*b*) = *k*}.

The terms 1/*a* for *a* ∈ *A_k* have *p*-adic valuation *v_p*(1/*a*) = −*k*.

#### The exact theorem this route would need

**Theorem B (Layer-Peeling Bound).** Let *Q* be a finite set of *y*-smooth composites. In any primitive reciprocal identity (*A*, *B*) in *Q*:

(i) For each prime *p* ≤ *y*, the elements of *A* ∪ *B* span at most *g*(*y*) distinct *p*-adic valuation levels.

(ii) At each *p*-adic level, at most *h*(*y*) elements from *A* ∪ *B* participate.

Together, these give |*A*| + |*B*| ≤ π(*y*) · *g*(*y*) · *h*(*y*).

#### Why it might be true

**For claim (ii):** At the extremal *p*-adic level (say the maximum *v_p* = *M*), the terms 1/*a* for *a* ∈ *A_M* ∪ *B_M* have the lowest *p*-adic valuation (−*M*). For the full sum to be zero, these extremal terms must cancel mod *p*. After dividing out *p*^{−*M*}, the reduced terms *p*^*M*/*a* are coprime to *p*. Their sum mod *p* must cancel between sides *A_M* and *B_M*. 

In a primitive identity, this cancellation must be "tight" — adding any element would break primitivity. For fixed *p*, the reduced values mod *p* form a subset of {1, …, *p*−1}, and a minimal cancellation mod *p* uses at most *p*−1 terms (by Davenport's constant for ℤ_*p*, which is *p*). So *h*(*y*) ≤ *y* (taking the largest prime ≤ *y*).

**For claim (i):** This is the critical and harder claim. In a primitive identity, after peeling off the extremal *p*-layer, the residual identity involves elements at lower *p*-adic levels. If this residual identity is itself decomposable, the original identity wouldn't be primitive. So the residual must form a primitive identity in the reduced system. By induction on the number of levels, we might bound *g*(*y*).

#### First nontrivial lemma to prove

**Lemma B1 (Extremal layer constraint).** In a primitive reciprocal identity (*A*, *B*) among *y*-smooth composites, for each prime *p* ≤ *y*, at least 2 elements of *A* ∪ *B* attain the maximum *p*-adic valuation (one on each side, or two on one side to cancel).

More precisely: let *M* = max_{*q* ∈ *A*∪*B*} *v_p*(*q*). Then |*A_M*| + |*B_M*| ≥ 2.

*Why this is true:* If only one element *q*₀ ∈ *A* ∪ *B* has *v_p*(*q*₀) = *M*, then after clearing denominators by *L* = lcm(*A* ∪ *B*), the term *L*/*q*₀ is divisible by *p*^{*M_p* − *M*} but NO other term is (they all have *v_p*(*L*/*q*) > *M_p* − *M*). Wait — this is backwards. Let me be more careful.

Actually, the element with the *highest v_p*(*q*) has the *smallest* 1/*q* contribution (in *p*-adic valuation terms, *v_p*(1/*q*) = −*v_p*(*q*) is the most negative). After clearing denominators, *w_q* = *L*/*q* has *v_p*(*w_q*) = *v_p*(*L*) − *v_p*(*q*), which is *smallest* for the largest *v_p*(*q*).

If *q*₀ uniquely maximizes *v_p*(*q*₀), then *w_{q₀}* uniquely minimizes *v_p*(*w_q*)*, say *v_p*(*w_{q₀}*) = *m*. All other *w_q* have *v_p*(*w_q*) ≥ *m* + 1. So in the identity ∑ ε_q *w_q* = 0, the term *w_{q₀}* has *v_p*-valuation exactly *m*, while ∑_{q ≠ q₀} ε_q *w_q* has *v_p*-valuation ≥ *m* + 1. So *p*^*m* | *w_{q₀}* but *p*^{*m*+1} ∤ *w_{q₀}*, while *p*^{*m*+1} | ∑_{q ≠ q₀} ε_q *w_q*. This contradicts ∑ ε_q *w_q* = 0.

So at least 2 elements must share the maximum *v_p*-valuation. This is **provable** and is a clean first lemma.

#### Most likely obstruction

**Claim (i) — bounding the number of valuation levels.** The argument above shows that at the extremal layer, ≥ 2 elements participate. After peeling this layer (by reducing modulo *p*^{*M*−*M*+1}), the residual may or may not be a new primitive identity. The issue is that the "peeling" operation can generate *new* terms or merge layers in complicated ways, and there's no clear induction that terminates after *O*(1) steps.

**Concrete obstruction:** Consider the identity

1/2 + 1/2^*n* = 1/(2·3) + 1/(2·3^2) + ⋯ + 1/(2·3^*k*)   (hypothetical)

where the LHS has elements at 2-adic levels 1 and *n*, while the RHS has elements at 2-adic level 1 but 3-adic levels 1 through *k*. If such an identity were primitive, the number of 3-adic levels grows with *k*. (We will check whether such identities can actually be primitive in Section 4.)

The fundamental issue: **the number of distinct *p*-adic levels is not bounded by the number of primes alone**; it depends on the range of exponents in *Q*, which grows with *N*. A proof via this route must show that primitivity forces the elements to use only *O*(1) levels per prime, which is plausible (the data suggests it) but unproved.

### 1.3 Strategy C: Anti-Concentration / Inverse Littlewood-Offord Route

#### Setup

The collision probability has an exact probabilistic representation:

CP(*Q*) = ℙ[∑_q ε_q / q = 0]

where each ε_q is independently: 0 with probability 1/2, +1 with probability 1/4, −1 with probability 1/4. This is because CP(*Q*) = ℙ_{*U*,*V* ~ Uniform(2^*Q*)}[*R*(*U*) = *R*(*V*)], and for each *q*, the contribution *q* ∈ *U* ∖ *V* (prob 1/4), *q* ∈ *V* ∖ *U* (prob 1/4), *q* ∈ *U* ∩ *V* or *q* ∉ *U* ∪ *V* (prob 1/2 total, zero contribution).

This is precisely the setup of the **Littlewood-Offord problem**: bounding the point probability ℙ[∑ ε_i *a_i* = *t*] where the *a_i* are given and the ε_i are random.

#### The exact theorem this route would need

**Theorem C (Inverse Anti-Concentration for Reciprocals).** Let *a*₁, …, *a_n* ∈ ℚ₊ be reciprocals of *y*-smooth composites. If

ℙ[∑ ε_i *a_i* = 0] ≥ 2^{−*n*+δ}

(i.e., CP is at least 2^δ times the "injective" baseline), then there exist disjoint *I*, *J* ⊆ {1, …, *n*} with |*I*| + |*J*| ≤ *C*(*y*, δ) and ∑_{*i* ∈ *I*} *a_i* = ∑_{*j* ∈ *J*} *a_j*.

#### Why it might be true — and the key rank observation

**Rank bound on subset sums.** For *y*-smooth *Q*, the reciprocals {1/*q* : *q* ∈ *Q*} lie in the additive subgroup ℤ[1/*p*₁, …, 1/*p_r*] of ℚ, which has rank *r* = π(*y*) as a ℤ-module. The subset sums *R*(*U*) lie in the non-negative cone of this rank-*r* group.

**Crucial consequence:** The number of distinct subset sums is polynomially bounded:

|Σ(*Q*)| ≤ *c_y* · |*Q*|^{π(*y*)}

for a constant *c_y* depending only on *y*. This is because the cleared-denominator sums ∑ *w_q* lie in a rank-π(*y*) lattice, and the sums are bounded by |*Q*| · max(*w_q*) in each "coordinate" — but more precisely, after a basis change to the prime-valuation coordinates, the number of achievable values is bounded by a polynomial in |*Q*| (and the range, but this is secondary).

**Why this forces large CP:** By Cauchy-Schwarz (or the second-moment method):

CP(*Q*) = ∑_t μ(*t*)² ≥ (∑_t μ(*t*))² / |support(μ)| = 1 / |Σ(*Q*)| ≥ 1 / (*c_y* · |*Q*|^{π(*y*)}).

So *H*₂(*Q*) ≤ π(*y*) · log₂|*Q*| + *O*(1), and the deficit satisfies:

**|*Q*| − *H*₂(*Q*) ≥ |*Q*| − π(*y*) · log₂|*Q*| − *O*(1).**

This is **linear in |*Q*|** for fixed *y*. So for *y*-smooth *Q* of size *n*, the deficit is automatically Ω(*n*), and the BSRCC hypothesis *D* ≥ δ is satisfied for all *n* ≥ *n*₀(*y*, δ). The conjecture reduces to:

**Reduced BSRCC.** For every *y*, every sufficiently large set of *y*-smooth composites contains a reciprocal identity of support ≤ *C*(*y*).

This is an **unconditional** statement — no entropy hypothesis needed! The entropy deficit is *automatic*.

#### Connection to inverse Littlewood-Offord

The classical **Tao-Vu inverse Littlewood-Offord theorem** says: if ℙ[∑ ε_i *a_i* ∈ {*t*}] ≥ *n*^{−*C*}, then most of the *a_i* belong to a generalized arithmetic progression (GAP) of bounded rank and small volume.

For our reciprocals, the "additive structure" detected by inverse LO would be: the values {1/*q*} lie in a GAP. For *y*-smooth *q*, they already lie in the rank-π(*y*) lattice ℤ[1/*p*₁, …, 1/*p_r*] — so the rank bound is automatically satisfied! The inverse LO conclusion is essentially trivial in this case.

What we need is a *stronger* conclusion: not just that the values have additive structure (we already know this), but that a *small subset sum identity* exists. This is a step beyond standard inverse LO.

**Possible adaptation via the Nguyen-Vu optimal inverse LO:** The Nguyen-Vu theorem gives *optimal* bounds on the rank and step sizes of the containing GAP. For our setting (atoms in a rank-*r* lattice), the theorem might give that the atoms lie in a GAP of rank *r* and volume *O*(*n*^*r*). Combined with a "pigeonhole on lattice points" argument, this could force short identities.

The key gap: **converting a GAP containment statement into a short identity existence statement.** This would require a new argument, possibly a combinatorial sieve on the lattice.

#### First nontrivial lemma to prove

**Lemma C1 (Polynomial image bound).** For *Q* a set of *y*-smooth composites with |*Q*| = *n*, we have |Σ(*Q*)| ≤ *c* · *n*^{π(*y*)} where *c* depends only on *y*.

*Proof sketch:* After clearing denominators by *L* = lcm(*Q*), the values *L* · *R*(*U*) = ∑_{*q* ∈ *U*} *L*/*q* are non-negative integers. Write each weight as *w_q* = *L*/*q* = ∏ *p_i*^{*M_i* − *v_{p_i}*(*q*)}. The subset sum *S*(*U*) = ∑_{*q* ∈ *U*} *w_q* is determined, modulo *p_i*^{*M_i*+1} for each *i*, by the sub-sums at each *p_i*-adic level. Using the Chinese Remainder Theorem and bounding the number of achievable residues at each prime level...

Actually, this requires more care. The correct argument is:

The subset sums *R*(*U*) lie in the set {∑_{*q* ∈ *U*} *c_q*/*L* : *U* ⊆ *Q*} where *c_q* = *L*/*q* ∈ ℤ₊. These are rationals with denominator *L*. The number of distinct values is at most the number of distinct integers ∑ *c_q* ε_q for ε_q ∈ {0,1}, which is at most 1 + ∑ *c_q* ≤ 1 + *n* · *L*/min(*Q*).

This is too crude. A better bound uses the fact that the *c_q* have bounded multiplicative complexity. Specifically, representing ∑ *c_q* ε_q in the basis {*p*₁^{*a*₁} ⋯ *p_r*^{*a_r*}}, the number of distinct values is bounded by the product of the ranges in each "coordinate." For a single prime *p*, the partial sums involving *p*-adic level *k* contribute at most *n* + 1 distinct values at that level. With at most *M* levels per prime and *r* primes, the total is (*n*+1)^{*r* · *M*}... which still involves *M*.

**A cleaner bound:** |Σ(*Q*)| ≤ min(2^*n*, |*B*|) where *B* is the number of lattice points in the box [0, ∑ *w_q*] ∩ (*w*-reachable set). For the Cauchy-Schwarz lower bound on CP, we only need |Σ(*Q*)| ≤ 2^*n*, which gives CP ≥ 2^{−*n*}, which is the "injective" baseline — not useful.

**Revised approach:** The polynomial bound |Σ(*Q*)| ≤ *c* · *n*^{π(*y*)} may not hold in general for arbitrary *y*-smooth weights. It holds when the weights span a bounded number of "scales" (magnitude ranges), but for *y*-smooth composites from [1, *N*] with *N* → ∞, the range of scales grows.

**Correction:** The deficit *D*(*Q*) ≥ δ is *not* automatic for all large *y*-smooth *Q*. If *Q* consists of *n* elements spread across exponentially different scales (like {2, 2², 2⁴, 2⁸, …}), subset sums are essentially unique (super-increasing sequence) and *D* ≈ 0. The deficit is large only when elements have *comparable* magnitudes relative to the lattice spacing.

This is an important correction to the above discussion. The deficit hypothesis in BSRCC is not vacuous — it genuinely requires the elements to have sufficient "overlap" in their reciprocal values.

#### Most likely obstruction

The main obstacle is the **gap between anti-concentration and identity existence**. Even with optimal inverse Littlewood-Offord bounds, the conclusion is about additive structure (GAP containment) rather than short identities. Converting one to the other requires:

1. Showing that the GAP is "dense enough" to force lattice collisions.
2. Showing that the collisions correspond to *short* identities, not arbitrarily long ones.

Both steps are non-trivial. Step 1 is related to the Freiman-Ruzsa theorem (inverse sumset theory), and Step 2 is related to the Graver basis problem (Strategy A). So this route may ultimately reduce to Strategy A.

## 2. Contrapositive Formulation

### Statement

**Contrapositive BSRCC.** For every *y* and *s*, there exists ε(*y*, *s*) → 0 (as *s* → ∞ for fixed *y*) such that: if *Q* is a set of *y*-smooth composites with no reciprocal identity of support ≤ *s*, then |*Q*| − *H*₂(*Q*) ≤ ε(*y*, *s*).

### Collision counting analysis

The entropy deficit is related to collision probability by *D* = |*Q*| − *H*₂ = |*Q*| + log₂ CP(*Q*). We have

CP(*Q*) = 2^{−2|*Q*|} · *N_col*

where *N_col* = #{(*A*, *B*) : *R*(*A*) = *R*(*B*)}. This decomposes as:

*N_col* = 2^{|*Q*|} + ∑_{identities (*C*,*D*)} 2^{|*Q*| − |*C*| − |*D*|}

where the sum is over all ordered pairs of disjoint nonempty subsets (*C*, *D*) with *R*(*C*) = *R*(*D*), and the first term counts diagonal pairs (*A* = *B*). This gives:

CP(*Q*) = 2^{−|*Q*|} · (1 + ∑_{(*C*,*D*)} 2^{−|*C*|−|*D*|})

So *D* = log₂(1 + ∑ 2^{−|*C*|−|*D*|}). If all identities have support |*C*| + |*D*| > *s*, then:

*D* ≤ log₂(1 + *N_id* · 2^{−(*s*+1)})

where *N_id* is the total number of (ordered) identity pairs. For generic *Q*, *N_id* can be at most 3^|*Q*| − 2^{|*Q*|+1} + 1 (all disjoint pairs minus non-identities), so:

*D* ≤ log₂(1 + 3^|*Q*| · 2^{−*s*−1}).

This gives *D* → 0 only if *s* ≫ |*Q*| · log₂ 3, which is useless (support grows with |*Q*|).

### A better bound via restricted identity counting

The crude bound *N_id* ≤ 3^|*Q*| is too wasteful. For *y*-smooth *Q* with minimum identity support > *s*, the number of identities is constrained by the lattice structure.

**Approach via Fourier analysis.** The collision probability has the Fourier representation:

CP(*Q*) = ∫₀¹ ∏_{*q* ∈ *Q*} (1/2 + (1/2) cos(2π*w_q* *t*)) *dt*

where *w_q* = *L*/*q* and we integrate over [0, 1) with respect to *t*. The integrand is non-negative (it's a product of terms in [0, 1]).

The contribution at *t* = 0 gives ∏(1/2 + 1/2) = 1, corresponding to the "trivial" contribution. For *t* ≠ 0, each factor (1/2 + (1/2)cos(2π*w_q* *t*)) = cos²(π*w_q* *t*) is at most 1 and equals 1 iff *w_q* *t* ∈ ℤ.

If no identity of support ≤ *s* exists, then for any *t* ≠ 0, at most... hmm, this connection is not direct. The Fourier integrand measures global resonance, not support of individual identities.

### Achievable contrapositive bounds from the data

From the computational evidence:

| *y* | Anti-support ≤ *s* | Observed *D* |
|---|---|---|
| composites ≤ 32 | ≤ 3 | 0.845 |
| composites ≤ 32 | ≤ 4 | 0.248 |
| composites ≤ 32 | ≤ 5 | 0.000 |
| 7-smooth, *N*=50 | ≤ 4 | 0.604 |
| 7-smooth, *N*=50 | ≤ 5 | 0.317 |
| 7-smooth, *N*=50 | ≤ 6 | 0.114 |

The pattern is roughly *D* ∝ 2^{−*s*/2} or *D* ∝ *s*^{−*c*}. This is consistent with ε(*y*, *s*) → 0 as *s* → ∞.

### Precise conjecture for the contrapositive

**Conjecture (Contrapositive).** For fixed *y*, if *Q* has no reciprocal identity of support ≤ *s* among *y*-smooth composites, then:

*D*(*Q*) ≤ *C_y* · 2^{−*s*/π(*y*)}

for some constant *C_y*. Equivalently, the "mass" of identities at support level *s* decays exponentially in *s*/π(*y*).

This would be consistent with the data (exponential decay in *s*) and would immediately imply BSRCC with *C*(*y*, δ) = *O*(π(*y*) · log(1/δ)).

## 3. Counterexample Attempts

We systematically attempt to construct *y*-smooth *Q_n* with large entropy deficit but all reciprocal identities having support tending to infinity.

### Attempt 1: Pure prime powers

**Construction:** *Q_n* = {*p*^*k* : *p* ≤ *y*, 2 ≤ *k* ≤ *n*} (composite prime powers).

**Result:** All subset sums are distinct (D = 0).

**Why it fails as a counterexample:** For a single prime *p*, the reciprocals 1/*p*^*k* are a super-increasing sequence (each term exceeds the sum of all smaller terms). For multiple primes, the reciprocals generate independent components: an identity ∑ 1/*p*^{*a_i*} + ∑ 1/*q*^{*b_j*} = ∑ 1/*p*^{*c_k*} + ∑ 1/*q*^{*d_l*} splits into separate identities for each prime (by *p*-adic independence), and each single-prime identity is impossible by super-increasing. So D = 0 — no deficit to work with.

**Lesson:** To have any deficit, we need "mixed" elements (products of multiple primes). But mixed elements are exactly what create small identities.

### Attempt 2: Geometric sequences of mixed elements

**Construction:** *Q_n* = {(*p* · *q*)^*k* : *k* = 1, …, *n*} for primes *p*, *q* ≤ *y*.

Example: {6, 36, 216, 1296, …} for *p* = 2, *q* = 3. Reciprocals: 1/6^*k*.

**Result:** This is a geometric sequence with ratio 1/6. Since 1/6 > 1/6² + 1/6³ + ⋯ = 1/30, the sequence is super-increasing. All subset sums are distinct, D = 0.

**Why it fails:** Geometric sequences with ratio < 1/2 are super-increasing, so no collisions.

### Attempt 3: Elements along a diagonal in exponent space

**Construction:** For primes {2, 3}, take *Q_n* = {2^*a* · 3^{*n*−*a*} : *a* = 0, 1, …, *n*} (all products with total exponent *n*, excluding 1).

Reciprocals: 1/(2^*a* · 3^{*n*−*a*}) = (2/3)^*a* / 3^*n*. An identity ∑ (2/3)^{*a_i*} = ∑ (2/3)^{*a_j*} with distinct *a_i* and *a_j* would require a vanishing sum of distinct powers of 2/3 — impossible since {(2/3)^*k*} are rationally independent over distinct integer exponents.

**Result:** D = 0 (no collisions). All subset sums are distinct.

**Why it fails:** Elements along a diagonal have reciprocals forming a geometric(-like) sequence with distinct ratios, preventing collisions.

### Attempt 4: Dense mixed elements at similar scales

**Construction:** All {2, 3}-smooth composites in [*N*/2, *N*]. For large *N*, these are composites 2^*a* · 3^*b* with *a*, *b* ≥ 0, 2^*a* · 3^*b* ∈ [*N*/2, *N*].

**Result:** This gives many elements at similar magnitudes, creating collisions. But the fundamental identity 1/(2^*a* · 3^*b*) + 1/(2^*c* · 3^*d*) = 1/(2^*e* · 3^*f*) + 1/(2^*g* · 3^*h*) with all four elements in [*N*/2, *N*] is precisely a support-4 identity.

**Why it fails as a counterexample:** Verified computationally: {4, 6, 9, 36} satisfies 1/4 + 1/36 = 1/6 + 1/9 (support 4). More generally, for any four {2,3}-smooth composites {*p*^*a*, *p*^*a* · *q*^*b*, *p*^*c* · *q*^*b*, *p*^*c*} forming a "rectangle" in exponent space (with appropriate constraints), a support-4 identity exists. Dense sets inevitably contain such rectangles.

**Key insight:** *The diamond identity.* For two primes *p*, *q* and exponents *a* > *c* ≥ 0, *b* > *d* ≥ 0:

1/(*p*^*a* · *q*^*d*) + 1/(*p*^*c* · *q*^*b*) = 1/(*p*^*a* · *q*^*b*) + 1/(*p*^*c* · *q*^*d*) (**FALSE** — this is always an identity when all terms are present, but it's the *trivial* rearrangement)

Actually, the non-trivial support-4 identity is:

1/*p*^*a* + 1/(*p*^*c* · *q*^*d*) = 1/(*p*^*e* · *q*^*f*) + 1/(*p*^*g* · *q*^*h*)

which requires specific exponent relations. The verified example is 1/4 + 1/36 = 1/6 + 1/9, i.e., 1/2² + 1/(2²·3²) = 1/(2·3) + 1/3², which after clearing by 36: 9 + 1 = 6 + 4, i.e., 10 = 10. ✓

This identity exists whenever a set contains four elements forming this "cross pattern" in exponent space: (2,0), (2,2), (1,1), (0,2). Any scaling of this pattern (multiply all elements by 2^*j* · 3^*k*) gives another support-4 identity.

To avoid ALL support-4 identities of this cross type, the set must avoid all such rectangles in exponent space. But for dense sets of {2,3}-smooth composites, avoiding all rectangles severely limits the set size (by Kővári–Sós–Turán or similar).

### Attempt 5: Sparse sets along a convex curve

**Construction:** Take *Q_n* = {2^{*f*(*i*)} · 3^{*g*(*i*)} : *i* = 1, …, *n*} where (*f*(*i*), *g*(*i*)) lie along a convex curve in exponent space, e.g., *f*(*i*) = *i*², *g*(*i*) = (*n* − *i*)².

**Why convexity might help:** Convex configurations in the exponent plane tend to avoid the "cross" pattern (which requires a kind of additive structure among exponent vectors). Specifically, four points on a strictly convex curve cannot form a parallelogram.

**But:** Convexity prevents parallelogram-type patterns but not all support-4 identities. The identity 9 + 1 = 6 + 4 (from exponent points (2,0), (0,2), (1,1), (2,2)) does *not* require a parallelogram; it's an "additive" coincidence among the weights *w_q* = 36/*q*.

**Result:** For elements along a convex curve, the weights *w_q* vary widely (exponentially in the exponents), and exact additive coincidences become increasingly rare but potentially never disappear entirely. This construction gives D ≈ 0 for most parameter choices (elements too spread out for collisions) but doesn't provide a clear counterexample with large D.

### Attempt 6: Iterated blowup construction

**Construction:** Start with a "base" identity of support *s*₀. Try to "shield" it by embedding it in a larger set where all identities have support ≥ *s*₀ + 1.

Specifically: take a support-*s*₀ identity (*A*₀, *B*₀) and add elements to *Q* that don't participate in any support-≤*s*₀ identity with elements of *A*₀ ∪ *B*₀.

**Problem:** Adding elements to *Q* can only *create* new identities (if an identity exists in *Q*, it also exists in *Q* ∪ {*x*}). So embedding doesn't help — the original support-*s*₀ identity persists.

To increase minimum support, we'd need to *remove* an element from each support-*s*₀ identity. But the base identity (*A*₀, *B*₀) is itself in *Q*, so we'd need to remove at least one element from *A*₀ ∪ *B*₀, destroying the identity. This is the correct approach but it doesn't produce a counterexample with *growing* minimum support.

### Summary of counterexample attempts

| Attempt | Deficit *D* | Min support | Why it fails |
|---|---|---|---|
| Pure prime powers | 0 | ∞ | No collisions |
| Geometric mixed | 0 | ∞ | Super-increasing |
| Diagonal in exp. space | 0 | ∞ | Rationally independent |
| Dense at similar scale | Large | 3–4 | Creates small identities |
| Convex curve | ≈ 0 | Large | No collisions |
| Iterated blowup | — | — | Can't increase support |

**Conclusion:** Every construction that achieves large deficit *D* simultaneously creates small-support identities. Every construction that avoids small identities achieves *D* ≈ 0. This is strong heuristic evidence **for** the conjecture. The underlying reason appears to be:

> *The mechanism that creates collisions (many elements with comparable reciprocal magnitudes in a low-rank lattice) is the same mechanism that creates short identities (low-dimensional additive coincidences among nearby lattice points).*

This is not a proof, but it suggests the conjecture captures a real phenomenon rather than a finite-universe artifact.

### Why no counterexample family exists (heuristic argument)

For *y*-smooth *Q* of size *n*, the subset sums live in a rank-*r* lattice (*r* = π(*y*)). If the deficit *D* ≥ δ > 0, then by the deficit formula:

∑_{identities (*C*,*D*)} 2^{−|*C*|−|*D*|} ≥ 2^δ − 1 > 0.

If every identity has support > *s*, then:

∑_{|*C*|+|*D*| > *s*} 2^{−|*C*|−|*D*|} ≥ 2^δ − 1.

Each term in the sum is at most 2^{−(*s*+1)}. So the number of identities is at least (2^δ − 1) · 2^{*s*+1}. These identities are elements of the integer kernel (after clearing denominators) with {−1, 0, +1} entries, living in a rank-*r* lattice.

The Graver basis elements in a rank-*r* lattice have a *conformal decomposition property*: every kernel element decomposes into a sum of Graver elements. If all Graver elements had support > *s*, then the total number of distinct Graver elements would need to be large enough to generate (2^δ − 1) · 2^{*s*+1} kernel elements of support > *s*. In a rank-*r* lattice, the number of "short" Graver elements (support ≤ *f*(*r*)) is finite for any fixed bound. If this finite set can generate all kernel elements, then *s* is bounded by *f*(*r*).

This argument would close the loop IF we could prove that the Graver basis of the reciprocal weight kernel for *y*-smooth composites has bounded support. This is exactly Strategy A.

## 4. Lean-Friendly Lemmas Worth Formalizing Next

Based on the proof strategy analysis, the following lemmas are worth formalizing in Lean, ordered by importance and accessibility:

### Tier 1: Immediately provable, directly useful

1. **Collision-Identity Decomposition Formula.** 

   Formally: `collisionCount Q = 2^|Q| + ∑_{(C,D) identity} 2^{|Q| - |C| - |D|}`
   
   This decomposes the collision count into the diagonal contribution and the identity contributions. It's elementary (partition the pairs (A,B) by their symmetric difference) and underlies the contrapositive formulation.

2. **Extremal valuation constraint (Lemma B1).**

   Formally: For any prime p and primitive identity (A,B) among positive rationals, if q₀ ∈ A∪B uniquely maximizes v_p(q₀), then the identity is not primitive (can be reduced by removing q₀).
   
   Equivalently: in a reciprocal identity (not necessarily primitive), at least two elements share the maximum p-adic valuation.
   
   This is a clean p-adic argument and directly formalizable.

3. **Super-increasing injectivity.**

   Formally: If Q is ordered q₁ < q₂ < ... < qₙ and 1/qₖ > ∑_{j>k} 1/qⱼ for all k, then the subset-sum map is injective (D = 0).
   
   Standard argument, useful as a tool for verifying that certain constructions have D = 0.

### Tier 2: Requires more work, but accessible

4. **Diamond identity characterization for two primes.**

   For p, q distinct primes and a,b,c,d ∈ ℕ with appropriate conditions, the identity 1/(p^a) + 1/(p^c · q^b) = 1/(p^a · q^b) + 1/(p^c) never holds (it's always equality, hence trivial). But 1/(p^a · q^d) + 1/(p^c · q^b) ≠ 1/(p^e · q^f) + 1/(p^g · q^h) in general; characterize when equality holds.
   
   This requires case analysis on exponents but is purely combinatorial.

5. **Deficit formula in terms of identity mass.**

   *D*(*Q*) = log₂(1 + ∑_{identities} 2^{−support}). This is a direct reformulation of the collision probability formula.

### Tier 3: Interesting but harder

6. **Graver element support bound for rank-1 kernel with two-prime weights.**

   Prove that for weights of the form {2^a · 3^b}, every primitive {-1,0,1} partition identity has support ≤ C for some explicit C. This would be a significant step toward Strategy A.

7. **No primitive identity among powers of a single prime.**

   For Q ⊆ {p^k : k ≥ 2}, prove there are no reciprocal identities at all (not just primitive ones). This follows from the super-increasing property of {1/p^k}.

## 5. Extended Analysis

### Why the conjecture is likely true for y = 3 (primes {2, 3})

For {2, 3}-smooth composites *Q*, the weights *w_q* = *L*/*q* are {2, 3}-smooth positive integers. A primitive {-1, 0, 1} partition identity ∑_{S⁺} *w_i* = ∑_{S⁻} *w_j* requires the two sums to be equal.

Write *w_i* = 2^{*a_i*} · 3^{*b_i*}. The identity ∑ 2^{*a_i*} · 3^{*b_i*} = ∑ 2^{*a_j*} · 3^{*b_j*} (sums over S⁺ and S⁻) is a Diophantine equation in {2, 3}-smooth numbers.

**Layer-peeling for p = 2:** Consider the terms with the smallest 2-adic valuation (i.e., the largest 2-exponent in 1/*q*, or equivalently the smallest 2-exponent in *w_q*). By Lemma B1, at least 2 elements share this minimum. Their contributions mod 2 must cancel (since the total sum is 0 mod 2^{min+1}). For 3^*b* mod 2 = 1 always, so the number of terms at the minimal 2-layer must be even. So ≥ 2, and their 3-adic parts must cancel in pairs mod 2.

**After one peel:** Remove the matched pair at the minimal 2-layer. The residual identity has one fewer 2-layer. By induction, the total support is bounded by 2 × (number of 2-layers). Similarly for 3-layers.

The question is: how many layers? For a *primitive* identity, adding a redundant layer would make the identity decomposable. So the number of layers should be bounded by the "width" of the primitive element, which for rank-1 kernels with {2,3}-smooth weights...

This is where the argument gets difficult. The number of layers is related to the number of distinct exponent values, which can grow. But primitivity constrains how layers interact — each layer must be "necessary" for the identity.

**Tentative bound:** For {2, 3}-smooth, the support of a primitive identity is at most 6 (three 2-layers × two elements per layer, constrained by 3-adic cancellation). The computational evidence (support 4 for {2,3}-smooth) is consistent with this.

### Critical assessment

**Is the data explained by a bounded-support theorem?** Most likely yes, for fixed *y*. The mechanism analysis (collision requires similar-scale elements, similar-scale elements in a low-rank lattice force short identities) is internally consistent and matches all computational observations.

**Is *C*(*y*, δ) likely independent of δ?** The data suggests *yes* for fixed *y*: forbidding support ≤ 6 makes the deficit very small regardless of the initial deficit. This would mean BSRCC simplifies to "every large enough *y*-smooth set has a support-≤*C*(*y*) identity." The δ parameter becomes redundant.

**Is the support-7 value universal for y ∈ {7, 11, 13}?** This is puzzling and could indicate that the tested ranges are too small to see the true *C*(*y*). For *y* = 13 (6 primes), if *C* depended linearly on π(*y*), we'd expect *C* ≈ 12 or more. The observed 7 might be because:
(a) the elements tested are too small to see higher-support primitives,
(b) the true bound is around 7 for all tested *y* (perhaps dominated by small-prime structure), or
(c) *C*(*y*) grows very slowly (e.g., *C* ~ 2π(*y*) + 1 for small *y* but stabilizes).

Further experiments with *y* = 23 (9 primes) and larger *N* would help discriminate.

### Relation between the three strategies

The three strategies are not independent:

- **A (Graver) and B (layer-peeling)** are closely related. Layer-peeling is essentially a constructive proof strategy for the Graver support bound, using the *p*-adic structure. If layer-peeling works, it gives a Graver bound. Conversely, a Graver bound would imply layer-peeling terminates.

- **C (anti-concentration) and A (Graver)** are complementary. Anti-concentration gives a *counting* lower bound on the number of identities (many identities must exist if deficit is large). Graver theory gives a *structural* upper bound on the size of primitive identities. Together: many identities exist, and each decomposes into short primitives, so short primitives exist.

The most promising combined strategy is:
1. Use the Fourier/anti-concentration approach (Strategy C) to show that large deficit forces exponentially many identities.
2. Use the conformal decomposition theorem (Graver theory, Strategy A) to decompose these into primitive elements.
3. Use the *p*-adic layer-peeling (Strategy B) to bound the support of primitive elements.

## 7. Summary: Most Promising Path Forward

1. **Prove Lemma B1** (extremal valuation constraint) — clean, formalizable, and foundational.

2. **Prove the two-prime case** (Lemma A1 / full analysis for *y* = 3). The exponent lattice is 2-dimensional, and a complete classification of primitive {−1, 0, +1} identities among {2, 3}-smooth numbers should be achievable. Expected result: support ≤ 4.

3. **Prove the collision-identity decomposition formula** to make the contrapositive quantitative.

4. **Attempt the layer-peeling induction** for general *r*: show that each prime reduces the "active" elements by a factor related to the Davenport constant of ℤ_*p*, giving total support ≤ ∑_{*p* ≤ *y*} *p* or similar.

5. **Contact Geroldinger** about the specific question of Graver support bounds for smooth weights.

The two-prime case (*y* = 3) is the critical test case. If it can be settled, the techniques will likely generalize (with increasing difficulty) to larger *y*.
