# Retired / nonclosing routes

## Physical Hilbert-HMRD caller

The abstract finite Hilbert-HMRD theorem is kernel-checked. The physical delta + single-Poisson caller is not constructed and is nonclosing as the current R11 route. The formal bank leaves the physical caller, vector-Mobius bound and global-mode ledger uninhabited.

## Independent absolute `P_med` child

The post-R11 recompiler no longer requires `P_med` as an independent sequential closure theorem. It was an overstrong child relative to the signed parent reassembly.

Retirement does not mean every intermediate lemma in these routes is false.
