# False / counterexampled formulations

## Free-`gamma` strong CARD5 lower bounds

The strong lower bounds

```text
M >= 2/5 + 6 epsilon/5,
N >= 1/3 + 2 epsilon/3
```

are **not** consequences of the supplied CARD5 chamber inequalities when `gamma` is free. The 5 September R11 formal bank contains kernel-checked counterexamples.

They become derivable only with the additional pin

```text
gamma <= 1/2 - epsilon.
```

This is an actual false implication, rather than a merely retired research route.
