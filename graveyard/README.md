# GRAVEYARD

This directory records routes that should **not** be treated as current research targets.

The subcategories are semantically distinct:

- [`false/`](false/) — an actual implication/theorem form is refuted by a counterexample or no-go.
- [`retired/`](retired/) — route may contain valid mathematics but is nonclosing, source-mismatched, or unnecessarily strong.
- [`superseded/`](superseded/) — old coordinate system replaced by a better parent/reassembly.

A graveyard entry is not automatically a statement that every lemma used by the route is false.
